# Advent of Code 2025 in Forth

Developed using gforth 0.7.3.

## Running

```shell
gforth --data-stack-size=32k 01_1.fs 01_input.fs -e 'input solve cr bye'
```

You have to supply the puzzle input files yourself.
Look at the `example-input` variables to determine how to derive the `input` definitions from the official puzzle input files.
